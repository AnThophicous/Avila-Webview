# Clean Distribution Layout

`buildclear/dist` is the clean release snapshot. It is the last packaged output mirrored from the source repository.

## Included

```txt
buildclear/
  Versionate.txt
  dist/
    <OutputName>.exe
    <OutputName>.avwmeta.json
    Versionate.txt
    build-report.txt
    app/
      avila.json
      src/
    logs/
```

## Excluded

- source tree
- `bin`
- `obj`
- debug symbols
- XML docs generated by dependencies
- temporary publish folders
- WebView2 user data
- logs outside the final package
- old app build outputs
- top-level managed DLL leftovers from publish

## CLI Commands

```powershell
.\avila.exe doctor --project path\to\app.avw
.\avila.exe create app my-app
.\avila.exe build --project path\to\app.avw
.\avila.exe package --project path\to\app.avw
.\avila.exe version
```

## Packaging Behavior

In source mode, `avila package` publishes the runtime, copies the app into `dist/app`, writes the metadata and report files, and stores `Versionate.txt` next to the packaged EXE.

After that, `buildclear/dist` is reset and mirrored from the final package output. The mirror is intentionally clean so launcher and smoke-test runs always point at the latest release.
