# Overview

Avila is a Windows desktop app engine for HTML, CSS, and JavaScript apps.
It is built on .NET 8 and WebView2 and is designed for teams that want a
strict, packageable runtime instead of a general-purpose browser shell.

## What People Search For

These terms all describe the same platform direction:

- WebView2 desktop app engine
- Windows desktop runtime for HTML/CSS/JavaScript apps
- Electron alternative for Windows apps
- .NET desktop engine for web frontends
- secure EXE packaging for browser-based apps
- AppView and BrowserApp runtime modes
- signed bundle packaging and tamper detection

## What It Includes

- `Avila.CLI` for `create`, `dev`, `build`, `package`, `verify`, `audit`, and `publish`
- `Avila.Security` for policies, capabilities, and bundle integrity checks
- `Avila.Runtime` for the WebView2 host and window lifecycle
- `Avila.Packager` for clean EXE output and secure bundle sealing
- `Avila.SDK` for the `avila.js` browser bridge

## Intended Uses

- internal tools
- customer-facing desktop apps
- dashboards and admin panels
- kiosk-style apps
- browser app shells
- web frontends packaged as signed Windows executables
